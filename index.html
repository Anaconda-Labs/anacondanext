Maps with Python — what changes when we flatten the world?

A sailor needs a steady bearing. A reader comparing countries needs fair areas. Every flat map is an optimization problem, so we built the tradeoffs you can feel: drag a real globe, then watch Tissot's distortion circles stretch across Mercator, Gall–Peters, Equal Earth, and AuthaGraph.

Everything runs locally in your browser — the geodesy is computed by NumPy in Pyodide, the globe is rendered with Three.js, and every projection's math is cited down to the paper.

Question → Action → Evidence → Decision

Every incubation run follows one operating formula. Prototypes stay subordinate to decisions, negative results are first-class, and evidence generation stays separate from production ownership.

01
Question A precise, falsifiable question — not a feature request.
02
Action The smallest real build that can generate evidence.
03
Evidence Numbers, demos, and failure modes — published either way.
04
Decision Ship, transfer, continue, or kill. All four are wins.
05
Next evidence What would change the decision if it arrived tomorrow.

Partnership explorations

Trusted Python, wherever agents run

We test our thesis — that agents deserve affirmatively trusted environments, not just vulnerability warnings — in conversations with the people building the platforms agents will live on.

⬢ GitHub — Copilot Cloud Agents

GitHub's Advisory Database helps an agent avoid known bad packages. Anaconda's controlled intake, independent builds, and malware scanning establish that an unknown package is trusted. Two different layers of the same defense.

Three paths surfaced from the conversation: an Anaconda-maintained base image for GitHub's emerging cloud-agent microVM runtime, a setup-anaconda Action for approved channels on Actions runners, and Anaconda MCP + skills in GitHub's plugin marketplace.

Next: one focused prototype, one defined end-to-end Secure Python experience, named technical owners.
☁️ Nebius — GPU capacity & orchestration

Metaflow orchestration has run against Nebius compute pools since March 2025, with capacity-block pools and perimeter-scoped reserved pools now self-serve. The evidence pack we compiled ranks what customers actually need: a second GPU source without re-plumbing, and honest operational transparency.

The same evidence names the gaps — environment reproducibility, cost attribution, supply-chain governance for whatever runs on the GPU. That's exactly where the incubation bets aim.

Next: measured baselines before any workflow ROI claims. Instrumentation first, marketing later.
